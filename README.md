# OCharSilo

离线优先的 OC（原创角色）稿件管理器。纯前端**单文件应用**，数据只存在你自己的浏览器里。

## ✨ 功能

- **稿件管理**：标题、作者、角色、标签、价格、附件、画廊封面
- **自定义字段**：文本 / 下拉 / 滑块 / 进度 等多种类型，可保存模板
- **主题系统**：内置多套主题（Y2K、新拟物风、童话梦幻系、复古未来主义、昭和宣纸、杂志编辑），支持导入导出 `.oc-theme`
- **离线优先**：基于 IndexedDB 本地存储，断网也能用
- **云同步（可选）**：可把自己配置的 WebDAV / S3（兼容 R2、MinIO、阿里云 OSS、腾讯云 COS）作为同步后端
- **可安装为 PWA**：装到手机主屏 / 桌面，全屏运行

## 🚀 快速开始

最简单：直接用浏览器打开 `index.html` 即可使用，**不需要任何服务器、也不需要联网**。

## 🌐 部署为可安装的 PWA（可选）

想把应用部署到自己的域名、让别人也能「安装到主屏」：

```bash
node build_pwa.js
```

会在 `dist/` 目录生成完整静态站点（`index.html`、`manifest.webmanifest`、`sw.js`、图标）。把 `dist/` 整个目录上传到任意静态托管（GitHub Pages / Cloudflare Pages / Vercel / Netlify / 自己的服务器，需 https）即可。

> 更新时重新跑一次 `node build_pwa.js`，覆盖 `dist/` 即可。Service Worker 的缓存版本号每次构建都会变，用户下次打开会自动拿到新版。

## ☁️ 云同步怎么配

应用本身**不自带云端账户**。要手机和电脑互通，进入应用内「⚙️ 系统配置 → ☁️ 云同步」，填入你自己的 WebDAV 或 S3 凭证。

## 🧱 技术说明

- **单文件架构**：所有 HTML / CSS / JS 都内联在 `index.html` 里，零外部依赖、零构建步骤。
- **数据存储**：IndexedDB；图片等大文件以 Blob 分离存储，根治内存膨胀（OOM）。
- **隐私**：你的数据只存在本地浏览器。除非你主动配置云同步，否则不会上传到任何服务器。
